# U-SAFE 공개 시연

울산 산업물류·보행안전 점검 지원 웹서비스의 공개 가능한 기능을 모은 독립 배포본입니다. 비공개 전체 구현 저장소의 Git 이력은 포함하지 않습니다.

## 직접 이용 가능한 기능

- 안전지도: 화물차 15개·보행자 38개 사고다발지역 기록, 필터, 상세 정보, 규칙 기반 일반 점검 준비 요약.
- 점검 후보 탐색: 원본 도형을 WGS84 → UTM 52N으로 변환한 뒤 최단거리 계산. 570개 조합에서 100/300/500m 이내 7/10/14쌍 탐색 및 두 기록 비교.
- 선택 후보를 AI 안내 화면으로 전달. 이 이동으로 AI를 호출하지 않음.

## 공개 시연 제한

|기능·자료|공개본|
|---|---|
|Gemini 신규 생성|항상 차단. POST /api/ai-briefing은 403, GET은 enabled:false 반환|
|공식 지침 PDF·원문·발췌문·페이지 추출본|미포함. 기관 공식 게시물 링크 제공|
|교통량 상세 JSON·원본 내장 HTML|미포함. 공식 자료 링크와 제한 안내 제공|
|과거 AI 응답·캡처·호출 기록|미포함|
|API 키·환경변수 값|미포함. 이 공개본은 키를 설정해도 AI 생성 기능 없음|

교통량·지침 원문의 재제공 조건을 확인하기 전 공개 범위를 제한한 것이며 이용금지가 확정됐다는 뜻은 아닙니다. 규칙 기반 요약은 프로젝트의 일반 점검 항목이며 공식 지침 인용이 아닙니다.

## 실행

Node.js 22 사용 권장.

```sh
npm ci
npm run verify
npm run dev
```

http://localhost:3000 에서 확인합니다. 배경 지도는 OpenStreetMap 타일 인터넷 연결이 필요합니다.

```sh
npm run lint
npm run build
npm run start
```

이 저장소는 공개 시연 구현만 포함합니다. 공식 자료 다운로드나 개인 키 설정으로 전체 AI·교통량 기능이 자동 복구되지 않습니다. 전체 구현은 별도 비공개 프로젝트에서 관리합니다.

## 데이터 출처와 이용조건

- 한국도로교통공단 [화물차 교통사고 다발지역](https://www.data.go.kr/data/15113414/openapi.do), [보행자 교통사고 다발지역](https://www.data.go.kr/data/15105289/openapi.do): 두 등록 페이지의 이용허락범위 제한 없음 확인(2026-10-19). 공식 CSV와 53개 기록·도형·수치 대조. 원본 변환 데이터의 내용 유지.
- 화물차: 2019~2024를 포함하는 4개 중첩 3년 집계의 선정 기록. 보행자: 2019~2025를 포함하는 5개 중첩 3년 집계의 선정 기록. 선정 ID 앞 연도는 사고 발생연도와 다름.
- [국토교통부 지침 게시물](https://www.molit.go.kr/USR/I0204/m_45/dtl.jsp?idx=18930&lcmspage=1&psize=10), [경찰청 편람 게시물](https://www.police.go.kr/user/bbs/BD_selectBbs.do?q_bbsCode=1001&q_bbscttSn=20250528151439314): 원문은 해당 기관에서 확인.
- [울산광역시 교통량 조사결과](https://www.its.ulsan.kr/help/survey.do): 공개본에 상세 수치 미포함.
- 지도 배경: OpenStreetMap 및 기여자. 지도 안의 출처 표시 유지. 외부 타일 서비스는 해당 제공자의 이용정책 적용.

## 해석 범위

53개는 고유 장소 수나 개별 사고 건수가 아닙니다. 후보 수는 기록 쌍 수이며 사고건수를 합산하지 않습니다. 공간적 인접성이 사고 연관성을 입증하지 않습니다. 탐색 거리 100/300/500m는 법적 설치기준이 아닙니다. 위험도·사고확률·사고 원인·시설 설치 의무를 판단하지 않습니다. 실제 현장 적용은 담당자의 별도 조사·검토가 필요합니다.
